# 图片存储与旧链接运维

## 升级与备份

升级前备份数据库、原图存储及现有 `APP_KEY`。策略凭证迁移会使用安装已有的 `APP_KEY` 加密。Docker 部署持久化整个 `storage` 目录。文件路径有三类：

- `storage/app/uploads` 保存旧版默认本地原图。
- `storage/app/media/objects` 保存新版本默认本地原图。配置了独立根目录的本地策略沿用该根，新对象位于其中的 `_lsky-media/v1/`。
- `storage/app/media/thumbnails` 保存按逻辑图片生成的私有 WebP 预览。可通过 `php artisan lsky:thumbnails` 重新生成。

升级后旧 `key.extension` 和通过应用源提供的本地策略链接仍可读取。原先标为私有的记录保留为「持链接可访问」，与迁移前的访问语义一致。支持旧链接的生产容器会将图片路径交由 PHP 做数据库查找和授权。传统部署需要移除网站根目录向旧媒体目录的静态映射，连同自定义媒体路径和旧的公开缩略图路径。外部 CDN、对象桶和 WebDAV 的原有直链由既有访问策略决定，需在对应平台调整公开访问和缓存。旧 SVG 可通过应用以附件方式取回，新上传仅接受受支持的栅格格式。

回退前应确认数据库、媒体对象及代码版本对应。已经接受新对象布局上传后，旧版程序无法直接读取这些对象，恢复时使用同一检查点的数据库和媒体备份。

## 访问与链接

新上传返回应用链接。公开图片可进入画廊，持链接图片从画廊隐藏。私有原图及其预览需要拥有者或管理员身份。私有原图可以签发 10 分钟链接，变更该图片访问权限会撤销此前签发的链接。外部桶、共享存储和自定义本地根需由管理员确认内部对象前缀没有独立匿名读取路径，再勾选对应私有存储选项。覆盖水印在入库前处理，动态水印用于应用交付和派生图。

同一请求重试可复用 `Idempotency-Key`。同一账户或游客 IP 上的相同标识和输入返回已保存记录，标识用于不同输入时请求会失败。新存储键一旦分配不可变，源文件名仍用于页面显示和 API 元数据。两段短事务分别保留配额和发布记录，原图写入在事务之间执行。失败时暂存记录提供回收依据。

## 对账和清理

- `php artisan lsky:media:audit --metadata-only` 仅读取旧版数据库，检查同一对象位置上记录了不同指纹的图片。
- `php artisan lsky:media:audit --strategy=1 --limit=500` 读取最多 500 条旧记录及对象。输出 JSON Lines，列出引用冲突、对象缺失、读取失败、指纹不一致和策略缺失。以最后一条汇总的 `last_image_id` 配合 `--after-id` 继续。返回码 1 表示有需人工核对的记录。审计会产生存储读取流量。
- 删除首先同步撤销应用访问，随后由调度器回收无引用对象。定期运行 `php artisan schedule:work` 或同等的 Laravel 调度器。需要即时处理积压时运行 `php artisan lsky:media:prune --limit=100`。失败任务按退避重试。停止的上传在保留期到期后加入清理队列。多实例部署应为调度器、派生图锁与审核缓存使用共享缓存，复用同一个数据库和持久媒体目录。
- 上传事务记录待生成缩略图状态。调度器定期离线生成，首次预览可以即时补建。内容审核接入阿里云时，受控审核 URL 依赖可达的规范应用地址、共享私有媒体存储和共享缓存。

识别异常后应对照对象版本和备份。记录中的哈希用于校验与定位差异，无法还原缺失或被覆盖的像素。
